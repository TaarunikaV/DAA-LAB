# Keyword & Plagiarism Search Tool (Naive / KMP / Rabin-Karp)

A simple Tkinter desktop application that searches a document for a
keyword or phrase using three classic string matching algorithms —
**Naive Search**, **KMP (Knuth-Morris-Pratt)**, and **Rabin-Karp** — and
compares their performance. Useful as a mini plagiarism/keyword checker.

## Main Features
- Paste or load a sample document into the text box
- Search for any keyword/phrase and see all match positions
- Compare Naive, KMP, and Rabin-Karp side by side: matches, comparisons, and time taken
- Run a performance analysis on a large random text with multiple pattern lengths
- Simple error handling for empty document/pattern or oversized pattern

## How to Run
```
python main.py
```
