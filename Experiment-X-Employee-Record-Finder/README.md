# Employee Record Finder (Interpolation Search)

A simple Tkinter desktop application that uses **Interpolation Search** to
quickly locate an employee record by Employee ID from a sorted, in-memory
employee database. Binary Search is included for direct performance
comparison.

## Main Features
- Search for an employee by ID using Interpolation Search
- View the record (ID, Name, Department), index found, comparisons made, and time taken
- Compare Interpolation Search vs Binary Search on the same query
- Run a full performance analysis across multiple dataset sizes
- Browse a sample of the employee database in a table view
- Simple error handling for invalid/empty input

## How to Run
```
python main.py
```
